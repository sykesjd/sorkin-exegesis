I gotta pause to point out how Joey's lines are formatted in the draft script, because the strategy used to denote when a line is signed, spoken, or interpreted is actually rather neatly done. The default formatting indicates Kenny is interpreting for Joey's signing without explicitly putting `(KENNY)` in the character header like I've been doing for this project, while Joey's actual speech is differentiated with _italicization_ — without explicitly putting that it's spoken rather than signed, once again. We don't have a draft script for episode 114 to cross-check if this strategy has been the case from the start, but with this exchange we also see a line in which Joey signs without interpretation is **bolded**. This time, though, it's paired with an explicit parenthetical that it's signed to Kenny, which indicates either that wasn't the case for the three relevant lines in 114 or the occurrence is rare enough that Mr. Sorkin found it prudent to (re-)provide the direction when it happens. Whichever the case, it's a well-done handling of writing for a deaf character, I'd say.
